# SkillLens

### Know your gap. Build your path.

SkillLens is an AI-powered career skill-gap analyzer designed for students and internship seekers.

It helps users understand how their current skills compare with the skills required for a target career role.

## Features

- Skill-based career gap analysis
- Target role selection
- Skill match percentage
- Matched, developing and missing skills
- Personalized learning roadmap
- Project recommendations based on skill gaps
- What-If skill coverage simulator
- Clean and responsive dashboard

## How It Works

1. Enter your current skills
2. Select a target career role
3. Analyze your skill profile
4. Identify skill gaps
5. Follow the personalized learning roadmap
6. Build the recommended project
7. Reassess your skill coverage
